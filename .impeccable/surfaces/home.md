# Quavok marketing site

Mode: Persuade.

## Confirmed direction

The owner's explicit additions pin both world and first-viewport experience: “Make the WHOLE site dark-themed by default”; “the Rocket-trial bot face set INLINE in the hero headline, which then detaches and travels with the visitor”; “a single dramatic accent light-beam/spotlight glow over the hero build”; “focus on what actually matters”. This is the existing code-led redesign already in progress, not a new comp selection. No workflow default has been set for future work.

## Direction contract

An operations studio where work visibly passes between four characterful cursors. The first viewport pairs a people-first promise and inline Rocket trial with a live, clearly illustrative workflow assembly. The customer's involvement is approval, not operating a builder.

Palette: Midnight #13251a, Forest #1f3d2b, Sand #e8dcc4, Purple field #392660, Electric Purple #8b5cf6, sand text #e8dcc4. Bricolage display has weight and width character; Inter handles explanation; mono identifies workflow roles and process steps.

Left-aligned promise beside the workflow on desktop; one continuous composition on mobile. A saturated dark-purple task wall is the scroll's colour peak. Automation examples use ruled index rows. Existing approval gates and run trace make the managed service concrete. The footer is anchored by an oversized QUAVOK wordmark.

Signature interaction: Rocket originates inside the headline, then travels/perches near the current section; asking opens an explicitly scripted quick-reply preview. Mobile stays compact and collapsible. Reduced motion gets static positioning and no eye movement/confetti.

## Bolder pass

Commit the problem section to a deep purple field. Make the workflow's four roles visible, with dotted handoffs and short speech. Replace the tiny, fixed-corner Pip with an inline-to-travelling Rocket trial. Give the footer enough typographic scale to close the page confidently. Avoid adding decoration to every other section.

## Quality bar

The product and primary action are clear without playing the intro. All eight routes remain usable, placeholders and form disclosure stay visible, and the conversational trial cannot be confused with live AI. Every control works with keyboard and touch. Capture 1440×900 and 390×844; inspect dark colour/contrast, preview open/closed/minimised, intro/replay/skip, graph and form states.
