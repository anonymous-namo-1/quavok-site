About Rocket.

Can Rocket build or change an automation?

No. Rocket forwards new requests to the Quavok team. We scope, build and run the automation with you.

Do I need Rocket to use Quavok?

No. Your automations run without it. Rocket is an optional way to interact with them.

What can Rocket see?

Rocket is designed to answer about the automations Quavok runs for your business. What it can access is agreed with you as part of the scope.

How can I get Rocket?

Ask for it when you discuss your automation with the Quavok team.
